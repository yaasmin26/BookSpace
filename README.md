
# BookSpace - Library Management System

BookSpace adalah aplikasi web untuk membantu pengelolaan perpustakaan.

## Teknologi
- PHP Native
- MySQL
- PDO
- Model View Controller (MVC)

## Fitur
- Login dan Logout
- Dashboard
- Manajemen Buku
- Manajemen Kategori
- Manajemen Anggota
- Peminjaman dan Pengembalian Buku

## Tim Pengembang
Project ini dikerjakan secara berkelompok.
